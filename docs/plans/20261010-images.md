# Image attachments

[Roadmap](../roadmap.md) · Future task · Depends on agents, conversations, and persistence; tools are optional

## Outcome

Attach images from files or the macOS clipboard, submit them with text or on their own, and retain exactly those images in the model request and saved conversation.

## Reference implementation

- `old:src/images.rs`: validated file/byte snapshots, image limits, and the asynchronous macOS clipboard worker.
- `old:src/lib.rs`: persistent image blocks; `old:src/providers.rs`: native image request payloads for both providers.
- `old:src/chat.rs`: attachment management, submission, and clipboard lifecycle.

Integrate attachment state into the existing draft and submitted request snapshot. Keep terminal Markdown image presentation in the interface plan; sending an image to a model is the capability covered here.

## Work within this task

### File attachments and persistent snapshots

- [ ] `/attach PATH` accepts PNG/JPEG/WebP, including paths with spaces. `/attachments` explicitly removes a selection; image-only submission works.
- [ ] Validate and snapshot bytes before submission. Source edits/deletion, the next draft, cancellation, and restart must not change an already submitted image. Send native payloads to both providers and persist the same snapshot with the turn.
- [ ] Validate before large allocations: 4 MiB input/image, 8 MiB new bytes/turn, 8192 pixels per side, 16 Mi pixels, 64 MiB decoded output, and 16 MiB session/request. Reject nonregular inputs such as FIFOs; detect format from content rather than extension. Treat decoder allocation budgets as best-effort.
- [ ] Validate saved snapshots on reload and avoid unnecessary base64 copies during read-only validation or rendering.

### Clipboard integration

- [ ] Ctrl+V reads the image clipboard once in a worker. Input remains available, and submission waits for the read to finish. Never read the clipboard during drawing.
- [ ] PNG/JPEG/WebP use the same validation; normalize TIFF to PNG after bounded checks. Text and file URLs do not automatically become image attachments.
- [ ] Bound worker output and use a 3-second watchdog with kill/reap. Handle empty/invalid/oversized input, timeout, and exit while the read is pending without freezing the editor or corrupting the next draft.

## Acceptance

Attach, remove, and submit an image with and without text. Verify exact payload bytes for both providers, source deletion after capture, save/restart, provider switching, and isolation of the next draft. Use fixtures for format/size errors and an explicit clipboard test double for worker failures; record actual macOS clipboard use and live model image understanding separately.
